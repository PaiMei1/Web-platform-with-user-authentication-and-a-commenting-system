# Web Platform with Authentication and Comment System

A full-stack web application implementing user authentication, authorization, and a comment management system. Users can register, log in securely, and interact through comments while practicing full-stack web development concepts.

## Features

- User registration and login system
- Secure authentication and authorization
- Comment creation and management system
- Database-driven storage of users and comments
- User session handling
- Responsive and user-friendly interface
- Structured backend and database integration
- Form validation and data processing
- And much more

## Technologies Used

- HTML
- CSS
- JavaScript
- SQL
- XAMPP
- phpMyAdmin

## Learning Objectives

This project was created to practice:

- Full-stack web development
- User authentication and authorization
- Database design and management
- SQL queries and data storage
- Session management
- Frontend and backend integration
- Web application architecture

## Installation

1. Install XAMPP
2. Place the project folder inside the `htdocs` directory
3. Start Apache and MySQL in XAMPP
4. Import the SQL database file into phpMyAdmin
5. Open the project in your browser:

```text
http://localhost/your-project-folder
